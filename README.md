# Змейка

Браузерная игра без установки, сборки и сервера. Достаточно открыть `index.html`.

## Запуск

Откройте файл `index.html` двойным щелчком. Страница работает по адресу `file://`.

Node.js, npm и локальный сервер не нужны.

## Управление

На компьютере по умолчанию включён режим «Мышь»: ведите курсор по полю, и змейка повернёт в его сторону. Переключатель «Мышь / Клавиатура» есть на стартовом и игровом экранах.

В режиме «Клавиатура»:

- стрелки или WASD — ход (WASD срабатывает по физической клавише, русская раскладка тоже подходит).

В обоих режимах:

- пробел, Escape или кнопка «Пауза» — пауза и продолжение;
- Enter — старт с главного экрана или новая партия с экрана результата.

После старта, рестарта и продолжения игра ждёт нового движения курсора внутри поля. Если курсор ушёл с поля или стоит слишком близко к голове, змейка едет как ехала. Разворот назад мышью не выполняется.

На телефоне:

- свайп по полю;
- экранные кнопки направлений;
- кнопка «Пауза».

Если свернуть вкладку во время партии, игра встаёт на паузу. Продолжить можно только вручную.

## Рекорд

Рекорд пишется в `localStorage` под ключом `snake-best-score`. При запуске через `file://` браузер может запретить хранилище. Тогда рекорд держится в памяти до закрытия страницы, а партия не прерывается. Повреждённое значение тоже не ломает игру.

## Цвета

Все цвета, отступы, скругления и основные размеры собраны в переменных `:root` в файле `styles.css`. Canvas читает те же цвета.

## Сложность

Числа партии лежат в объекте `CONFIG` в начале `script.js`:

- `gridSize` — сторона поля;
- `initialLength` — начальная длина;
- `initialTickMs` — интервал шага в начале, сейчас 250 миллисекунд;
- `minTickMs` — самый короткий интервал, сейчас 140 миллисекунд;
- `tickStepMs` — на сколько ускоряется игра;
- `foodsPerSpeedup` — сколько еды нужно для одного ускорения;
- `pointsPerFood` — очки за еду;
- `maxInputQueue` — сколько поворотов можно накопить между шагами;
- `bestScoreKey` — ключ рекорда.

Начальная длина должна помещаться на поле левее головы. Сейчас это 3 клетки около центра, направление — вправо.
