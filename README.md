# Змейка

Браузерная игра без сервера и внешних API. Поле рисуется на Canvas, интерфейс — обычной вёрсткой.

## Запуск

```bash
npm install
npm run dev
```

Сборка и локальный просмотр собранной версии:

```bash
npm run build
npm run preview
```

Тесты игровой логики запускаются встроенным тест-раннером Node.js 22.6 или новее:

```bash
npm test
```

Сборка кладёт статику в `dist`. Её можно выложить на любой статический хостинг: пути относительные.

## Управление

На компьютере:

- стрелки или WASD — ход (WASD срабатывает по физической клавише, русская раскладка тоже подходит);
- пробел или Escape — пауза и продолжение;
- Enter — старт с главного экрана или новая партия с экрана результата.

На телефоне:

- свайп по полю;
- экранные кнопки направлений;
- кнопка «Пауза».

Если свернуть вкладку во время партии, игра встаёт на паузу. Продолжить можно только вручную.

Рекорд хранится в `localStorage` под ключом `snake-best-score`. Если хранилище недоступно или значение повреждено, партия всё равно идёт, а рекорд для сессии начинается с нуля.

## Цвета и оформление

Все цвета, отступы, скругления и основные размеры собраны в переменных в `src/styles.css`, в блоке `:root`. Чтобы подогнать игру под бренд, достаточно поменять их там — Canvas читает те же цвета.

## Сложность

Числа партии лежат в `src/game/config.ts`:

- `GRID_SIZE` — сторона поля;
- `INITIAL_LENGTH` — начальная длина;
- `INITIAL_TICK_MS` — интервал шага в начале;
- `MIN_TICK_MS` — самый короткий интервал;
- `TICK_STEP_MS` — на сколько ускоряется игра;
- `FOODS_PER_SPEEDUP` — сколько еды нужно для одного ускорения;
- `POINTS_PER_FOOD` — очки за еду.

Начальная длина должна помещаться на поле левее головы. Сейчас это 3 клетки около центра, направление — вправо.
